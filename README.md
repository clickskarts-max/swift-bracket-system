# Ecluid Basketball

Tournament management for basketball organizers — leagues, group stages and
knockouts with live schedules, standings, brackets and shareable public
tournament pages.

## Development

You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS
